Час роботи депо

Це загальна рамка складу на день. Робочий час кожної машини: вікно на дату («Авто», жовті поля) → інакше графік водія (Налаштування → Водії) → результат обрізається цією рамкою.

Простій на точці

Історія — власні факти TMS («Прибув» → «Поїхав» по клієнт+адреса), нормативи оновлюються автоматично перед кожним розрахунком. «Хвилин» — для клієнтів без історії.
